# v0.3 设计文档 — Agent Loop 与工具执行

> 版本目标：让 Pace 真正成为一个可运行的 Agent 框架

---

## 一、背景与问题

### 1.1 当前状态

Pace 目前是一个**上下文管理框架**，而非完整的 Agent 框架：

| 能力 | 状态 | 说明 |
|------|------|------|
| 渐进式加载 (L0/L1/L2) | ✅ | 核心能力已实现 |
| LLM 适配器 | ✅ | OpenAI + Anthropic |
| 记忆管理 | ✅ | File + SQLite |
| 安全控制 | ✅ | 基础 S0 规则 |
| **Agent Loop** | ❌ | 缺失！只能单次调用 |
| **工具执行** | ❌ | 只有 Mock |
| **多 Agent 编排** | ❌ | 未实现 |

### 1.2 核心问题

**没有 Agent Loop = 不是真正的 Agent**

当前 `PaceRuntime.run()` 只做一次 LLM 调用，不会：
- 解析工具调用请求
- 执行工具
- 将结果返回给 LLM
- 循环直到完成

## 二、核心设计

### 2.1 Agent Loop

```
┌─────────────────────────────────────────────────────────────┐
│                      Agent Loop                              │
│                                                              │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐              │
│  │ Compile  │───▶│   LLM    │───▶│  Parse   │              │
│  │ Context  │    │  Call    │    │ Response │              │
│  └──────────┘    └──────────┘    └──────────┘              │
│       ▲                                │                    │
│       │                                ▼                    │
│       │                         ┌──────────┐               │
│       │                         │ Tool Call?│               │
│       │                         └──────────┘               │
│       │                              │                      │
│       │                    ┌─────────┴─────────┐           │
│       │                    │ Yes               │ No        │
│       │                    ▼                   ▼           │
│       │             ┌──────────┐        ┌──────────┐      │
│       │             │ Execute  │        │  Return  │      │
│       │             │  Tools   │        │  Result  │      │
│       │             └──────────┘        └──────────┘      │
│       │                    │                               │
│       │                    ▼                               │
│       │             ┌──────────┐                           │
│       └─────────────│  Update  │                           │
│        (L1 sticky)  │ Context  │                           │
│                     └──────────┘                           │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

**接口定义**：

```typescript
interface AgentLoopOptions {
  /** Maximum iterations (default: 50) */
  maxIterations?: number;

  /** Callback when tool is about to execute */
  onToolCall?: (tool: string, params: unknown) => Promise<void>;

  /** Callback when LLM response is received */
  onResponse?: (response: LLMResponse) => void;

  /** Callback when iteration completes */
  onIteration?: (iteration: number, context: AgentContext) => void;
}

interface AgentContext {
  /** Conversation history */
  messages: Message[];

  /** Tools available */
  tools: ToolDefinition[];

  /** Accumulated results */
  results: ToolResult[];

  /** Current iteration */
  iteration: number;

  /** Token usage */
  tokens: {
    input: number;
    output: number;
    total: number;
  };
}

interface AgentResult {
  /** Final response */
  response: string;

  /** Tool calls made */
  toolCalls: Array<{
    tool: string;
    params: unknown;
    result: unknown;
  }>;

  /** Total iterations */
  iterations: number;

  /** Token usage */
  tokens: {
    input: number;
    output: number;
    total: number;
  };

  /** Trace events */
  trace: TraceEvent[];
}
```

### 2.2 Tool Executor

**接口定义**：

```typescript
interface ToolExecutor {
  /**
   * Execute a tool and return the result
   */
  execute(toolCall: ToolCall): Promise<ToolResult>;

  /**
   * Get tool definitions for LLM
   */
  getDefinitions(): ToolDefinition[];

  /**
   * Register a new tool
   */
  register(tool: ToolDefinition, handler: ToolHandler): void;
}

type ToolHandler = (params: unknown, context: ToolContext) => Promise<unknown>;

interface ToolContext {
  /** Agent context */
  agent: AgentContext;

  /** Trace writer */
  trace: TraceWriter;

  /** Abort signal */
  signal?: AbortSignal;
}

interface ToolCall {
  /** Tool ID from LLM response */
  id: string;

  /** Tool name */
  name: string;

  /** Parameters */
  params: unknown;
}

interface ToolResult {
  /** Tool call ID */
  toolCallId: string;

  /** Tool name */
  toolName: string;

  /** Result content */
  content: string;

  /** Whether execution succeeded */
  success: boolean;

  /** Execution latency */
  latencyMs: number;
}
```

### 2.3 内置工具

提供一组开箱即用的工具：

| 工具 | 说明 | 风险等级 |
|------|------|----------|
| `read_file` | 读取文件 | low |
| `write_file` | 写入文件 | medium |
| `list_directory` | 列出目录 | low |
| `execute_shell` | 执行 shell 命令 | high |
| `http_fetch` | HTTP 请求 | medium |
| `search_web` | 网页搜索 | low |
